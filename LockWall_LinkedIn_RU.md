## 2) Полная статья

**Заголовок:** LockWall: бесплатная локальная защита Windows Server от брутфорса

**Запасные заголовки:**

```
Поднимаешь Windows-сервер с открытым в интернет RDP — и через пару часов его находят
боты. Журнал безопасности заполняется событиями 4625: неудачный вход, неудачный вход,
неудачный вход — с IP со всего мира, методично перебирающих admin / administrator / sa.
Большинство справляется так: переносит RDP с порта 3389, прячется за VPN или просто
живёт с этим шумом.

Я хотел инструмент, который просто разберётся с этим сам. Так появился LockWall.


ЧТО ЭТО

LockWall — бесплатная служба Windows, которая отслеживает неудачные входы и автоматически
блокирует атакующие IP в брандмауэре Windows — по трём самым атакуемым сервисам: RDP,
Outlook Web Access (OWA) и SQL Server.

Работает целиком на твоём сервере. Без облака, без агентов, без регистрации.


КАК ЭТО РАБОТАЕТ (без магии и драйверов ядра)

1. Читает журнал событий Windows — Security (событие 4625 для RDP и OWA) и Application
   (событие 18456 для SQL Server).
2. Считает неудачные попытки по каждому IP в пределах временного окна.
3. Когда IP превышает порог, LockWall добавляет его в правило блокировки брандмауэра
   через netsh — групповые правила, а не по одному на каждый IP.
4. Блокировки снимаются автоматически (по умолчанию через 7 дней) — или эскалируются
   для рецидивистов.

Это лёгкая служба на опросе журнала: в простое нагрузка на CPU около нуля, и даже под
шквалом атак она остаётся лёгкой.


ЧТО ВНУТРИ

• Защита RDP, OWA и SQL Server в одной службе
• Прогрессивная блокировка — нарастающая длительность для рецидивистов (1ч → 24ч → 7д → навсегда)
• Детект password-spray — ловит один IP, перебирающий много логинов
• Белый список с поддержкой CIDR — никогда не заблокируешь свой офис или VPN
• Локальный веб-дашборд — блокировки, аналитика, журнал аудита, проверка состояния
• Оповещения в Telegram и email (опционально)
• Опциональное GeoIP-обогащение — страна/город/ISP атакующего, по умолчанию выключено
• Несколько админов с ролями (Admin / Viewer) и экспорт в CSV


БЕСПЛАТНО — И ПОЧЕМУ

LockWall бесплатен навсегда. Все протоколы, все функции. Без лицензионных ключей, без
триала, без «Pro»-версии, без лимитов на число серверов. Ставь хоть на один сервер, хоть
на пятьдесят, дома или на работе.

Я сам гоняю его на своих боевых серверах каждый день. Делиться им мне ничего не стоит, а
реальная защита от потока брутфорса должна быть в руках у каждого админа — а не за
пейволлом.


ЗАКРЫТЫЙ ИСХОДНИК, НО ПРОВЕРЯЕМЫЙ

LockWall — проприетарный freeware, бинарник закрыт. Но для инструмента, который управляет
твоим брандмауэром, доверие важно как никогда. Поэтому каждый релиз проверяем: с ним идёт
контрольная сумма SHA-256 и скан VirusTotal. Текущая сборка — 0/61, ноль срабатываний у
антивирусов, даже без цифровой подписи.


КАК НАЧАТЬ

1. Скачай MSI со страницы релизов на GitHub и запусти — служба установится и стартует сама.
2. Открой дашборд по адресу http://127.0.0.1:8880 и задай пароль администратора.
3. Внеси свои доверенные сети в белый список (чтобы не заблокировать самого себя).

Вот и всё. Требования: Windows 10 / Server 2016 или новее, 64-bit.
```
